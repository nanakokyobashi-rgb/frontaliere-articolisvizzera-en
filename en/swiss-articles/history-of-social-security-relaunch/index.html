The website www.storiadellasicurezzasociale.ch is presented in a new guise. The new site has been extensively reworked to make the history of the Swiss welfare state even more accessible. The platform invites you to rediscover the content, both for the interested public and for researchers and teachers. The project has been supported for more than ten years by a consolidated collaboration between the main Swiss university schools and the Federal Office of Social Insurance (UFAS).

The new site features an interface and a new graphic design optimized for compatibility with all terminals and accessibility. The main new features include new navigation functions that make it easier to search and make the correlation between the various themes visible. The offer has been enriched by a learning platform dedicated to the history of social security in Switzerland (www.lab.storiadellasicurezzasociale.ch).
