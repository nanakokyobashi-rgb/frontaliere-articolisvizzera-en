Operational details

What the directory contains

The Ticino directory comes from the official cantonal list and the current snapshot contains 207 records. A record helps with names, addresses and published contacts; it is not real-time proof of opening and does not replace a phone call.

For a practical search, start with the Ticino route, open the pharmacy record and check which details are actually published. If you need duty information, move to the relevant regional source: do not treat the directory as a duty service.

Directory, opening hours and duty: three different data points

  • directory: A directory record means that the official catalogue contains the entry; it does not mean that the pharmacy is open now.
  • opening hours: Opening hours are shown only when the page or source publishes them; they are not inferred from the directory or its timestamp.
  • verified duty: Verified duty means a regional interval published by OFCT or the relevant association source; it is not the same as continuous opening. Check by phone before travelling.

Frequently Asked Questions
How many records are in the Ticino directory snapshot?
The current snapshot contains 207 records from the official cantonal list. The count may change at the next refresh.
Does a directory contact mean that a pharmacy is open?
No. The directory is an address record; for opening, hours or duty, read the available source and confirm directly.
Where can duty pharmacies be checked?
Verified duty is published on the regional sources for the five covered areas: Mendrisiotto, Luganese, Bellinzonese, Biasca e Valli and Locarnese.
